
# Silcar Clean — Simulador de compras

Aplicación web interactiva para simular la compra de productos de limpieza.

## Tecnologías
- HTML y CSS
- JavaScript
- Fetch y async/await
- JSON
- LocalStorage
- Toastify

## Funcionalidades
- Catálogo de productos cargado desde data.json
- Búsqueda y filtrado
- Carrito de compras
- Modificación de cantidades
- Cálculo automático del total
- Eliminación y vaciado del carrito
- Confirmación del pedido
- Persistencia del carrito mediante LocalStorage

## Cómo ejecutar
Abrir el proyecto en Visual Studio Code con Live Server.
